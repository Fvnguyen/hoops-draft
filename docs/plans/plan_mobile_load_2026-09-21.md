## Goal

The installed PWA is playable on a Galaxy S26+ over mobile data without a multi-second white screen: `/login`
stops shipping the 482 KB card set, avatars stop pulling full 1040x760 photos, the auth proxy stops running 8
Supabase round trips per load, and static art is served pre-shrunk with a long cache instead of re-transformed
or re-downloaded on every visit.

## Decisions (locked)

- D1 `CARD_SET_VERSION` moves to a new JSON-free `src/engine/cardSetVersion.ts`. `cards.ts` re-exports it;
  `storage/types.ts:19` and `build-cards.ts:17,38` import it from the new module, breaking the bootstrap loop
  where `build-cards.ts` (writes `cards.json`) imports `cards.ts` (reads the `cards.json` it is about to
  overwrite).
- D2 One card-set delivery path: a dynamic `import('@/engine/cards')` from game routes only, replacing
  `fetch('/api/cards')` at `DraftRoom.tsx:291`, `app/data/page.tsx:42`, `app/deckbuilder-test/page.tsx:62`
  (and the fixture fetch in `tests/roster-reopen.spec.ts`).
  `api/cards/route.ts` is deleted. The home page keeps re-rolling its hero + 4 pack cards on every
  visit (owner, 2026-09-21), but only ever draws Mythic/Rare: `build-cards.ts` also writes
  `src/data/showcase.json` (new, those 35 cards, 41 KB raw vs 482 KB) and `app/page.tsx:67` imports that
  instead of `getAllCards()`; `pickHero`/`pickPackPreview` are unchanged.
- D3 Avatar-size headshots (20-28px: `PlayTile.tsx:87`, `PlayPanel.tsx:127`, `AssignPopover.tsx:45`,
  `PlayerCard.tsx:1170/1214`, `DeckBuilder.tsx:525`) use a new committed `public/headshots/96/<id>.webp`,
  generated by `ensure-headshots.mjs` with `sharp` (already a dependency). One helper,
  `headshotThumb(id, size: 96 | 480)` in `src/lib/headshotThumb.ts` (new), is the only way a component builds
  a headshot URL.
- D4 Card-front headshots (`PlayerCard.tsx`, `sizes={HEADSHOT_SIZES}` = `'200px'`) use a pre-generated
  `public/headshots/480/<id>.webp` via `headshotThumb`, `<Image>` marked `unoptimized` (removes 481 images
  from Vercel's image-optimization quota; `next.config.ts` has no `images` block today, so the default
  14400s `minimumCacheTTL` applied). `pack_2025_2026.png`, `_variant_820.png` (`PackOpener.tsx:329`) and
  `cardback.jpg` (`PackRevealCard.tsx:29`), 2.6-3.2 MB each, are re-encoded to ~640px WebP.
- D5 `arena_16_9.jpg` (2.72 MB, CSS background at `page.tsx:97`) re-encodes to a 1600px-wide WebP.
  `next.config.ts` gets `headers()`: `/headshots/:path*`, `/logos/:path*`, `/icons/:path*` and the hero art
  get a 1-year immutable `Cache-Control` (`public/` serves at `max-age=0` today). Delete `public/players.json`
  (408 KB, unreferenced in `src`/`scripts`/`tests` by grep, distinct from the pipeline's own
  `data/players.json` written by `fetch_players.py:623`), `arena_vertical.jpg`,
  `pack_2025_2026_variant_1.png` (same grep, unreferenced).
- D6 `proxy.ts:99` matcher excludes `manifest.webmanifest`, `*.json`, `sw.js`, RSC prefetches. `getUser()`
  (`:71`) becomes `getClaims()` (present in installed `@supabase/auth-js@2.116.0`), verifying the JWT locally.
  `StorageProvider.tsx:58`'s duplicate `fetch('/api/auth/me')` is removed by `sync_outbox` D1 (it owns
  `StorageProvider.tsx`/`AuthProvider.tsx`), not here. `proxy.ts:84`'s `profiles` select is unchanged.
- D7 `storage/index.ts:5,9`'s static imports of `@/lib/supabase/browser` and `./supabase` become a dynamic
  `import()` inside `getGameStore()`/`setOwnerId()`, run once a profile id exists, moving the 378 KB/104 KB gz
  client out of the root layout chunk. `sync_outbox` owns this file: D7 starts only after `sync_outbox`
  is done, and only wraps the two imports.
- D8 `PlayerCard.tsx:477`/`:618`'s `backdrop-blur-sm`/`backdrop-blur` (over an opaque gradient, blurring
  nothing) are removed. The back face (`:787-797`'s `preserve-3d` `motion.div` mounts both faces
  unconditionally) renders only while flipped or on `(pointer: fine)`, since phones have no hover-flip and
  long-press already shows the back. `Geist_Mono` (`layout.tsx:21`) gets `preload: false`. The `onError`
  fallback at `PlayerCard.tsx:504-506` (a `transparenttextures.com` URL) becomes `/headshots/_missing.png`
  (`ensure-headshots.mjs:27`).
- D9 `manifest.ts` gets PNG icons (192, 512, maskable 512) and a 180px apple-touch-icon from
  `public/icons/icon.svg` via `sharp` (iOS ignores the current SVG-only set, `layout.tsx:30`), plus
  `id: '/'`, `scope: '/'`. `viewport` (`layout.tsx:45`) gains `themeColor: '#0c0a09'`.
  `ConfirmPickDock.tsx:31`'s `env(safe-area-inset-bottom)` is divided by `--zoom` (0.7 on phone,
  `globals.css:191-199`); the phone shell also gets left/right safe-area padding for the landscape cutout
  sides, currently unhandled.
- D10 `useAndroidBackGuard.ts` pushes a history entry on mount (`:35`) but never pops it when `enabled` turns
  false (`:44-47` only removes the listener), so DraftRoom's guard (disabled at `:231` once deckbuilding
  starts) leaves a dead entry under DeckBuilder's own guard (`:197`); `goBack()`'s fixed `history.go(-2)`
  (`:54`) then lands on the dead entry, so "Leave" does nothing. Fix: the cleanup effect pops the guard entry
  itself when `armedRef.current` is still true as `enabled` flips to false. `DeckBuilder.tsx:1057`'s post-save
  `router.push('/rosters')` becomes `router.replace`.
- D11 (LAST task, owner-overrulable) A same-origin-GET-only, cache-first service worker `public/sw.js` (new)
  for `/_next/static/*`, `/logos/*`, `/icons/*`, `/headshots/{96,480}/*`. Network-only for navigations,
  `/_rsc`, `/api/*`, Supabase (HTML is auth-gated by `proxy.ts`; caching it would bypass the gate, why
  `mobile_pwa_shell` was removed; this does not resurrect it). Caches named by build id, purged in
  `activate`. `sw.js` is `Cache-Control: no-cache`, excluded from the proxy matcher (D6). True offline play
  stays out of scope.

## Out of scope

beyond the D7 import wrap; `mode_picker`, `android_twa`; true offline play (D11); a native wrapper or
TWA-specific back-button API.
